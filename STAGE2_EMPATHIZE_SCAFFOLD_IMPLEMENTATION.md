# Stage 2 — Empathize + Hardest-Thinking Scaffolds

This file documents implementation of recommendations 16–27 from the Stage 2 plan.

## 16. Add a simple Empathy Map or visual output — IMPLEMENTED

Stage 1 now ends with a six-part visual Empathy Map:
- what the learner is trying to do;
- what they currently do;
- where it seems to become difficult;
- what they have already tried;
- direct interview/observation clues;
- what the team still needs to learn.

The map is saved in browser state, downloadable, included in the Stage 1 record, and carried visibly into Define.

## 17. Get students to the real interview faster — IMPLEMENTED

The former separate "Learn the basics" student screen was removed. The core sequence is now:
1. Start here
2. Two-minute quick build
3. Question Detective
4. Plan + conduct the real interview
5. Build the Empathy Map
6. Check together
7. Save and move on

The facilitator Session 1 plans were also rewritten so the real interview begins around minute 20 in the 45-minute path and during Session 1 in the two-session path.

## 18. Shorten neutral-question instruction — IMPLEMENTED

Question Detective now teaches only the minimum principle through two short choices. A compact question bank follows immediately and is reused in Interview Coach.

## 19. Reframe Question Detective as a game/challenge — IMPLEMENTED

Question Detective uses two "clues" rather than a quiz/scoreboard and gives immediate choice-based feedback.

## 20. Fix question-selection feedback — IMPLEMENTED

Students can change their answer after feedback. The interface no longer locks the first selection. Feedback explicitly identifies:
- what the student chose;
- why it is useful or less useful;
- the stronger question when needed;
- why the stronger question is better.

## 21. Simplify simulated AI interview setup — IMPLEMENTED

The optional practice tool now uses structured controls for:
- STEM area;
- learner context;
- general type of difficulty;
- optional specific topic.

Technical role-play detail is inferred in JavaScript rather than being generated by the student.

## 22. Make simulated practice optional or very short — IMPLEMENTED

AI interview practice is a collapsed "Optional 3-minute practice" inside the interview step. It is not required to continue and is explicitly labeled as practice, not evidence.

## 23. Avoid asking students to diagnose learning problems — IMPLEMENTED

Student-facing diagnosis language was removed. The workflow uses phrases such as:
- where it seems to get hard;
- what happened before that;
- what should we learn more about;
- best guess to test;
- clues to investigate.

The Empathy Map and Task Breakdown Helper explicitly avoid presenting a final answer about the learner.

## 24. Audit the hardest open-response boxes — IMPLEMENTED

All six student stage pages load a shared progressive open-response scaffold. Static textareas receive a collapsed "Need a starting point?" helper unless they already have a purpose-built scaffold. Dynamic one-question-at-a-time tools already provide question-specific explanations/examples/help.

The audit prioritized the hardest student-generated work:
- neutral interview questions → question bank + sentence starters;
- interview topic → sentence starters;
- Empathy Map → six concrete categories tied to interview evidence;
- task breakdown → visual step map + built-in helper;
- learning strategy → structured categories/cases;
- prompt design → guided one-question-at-a-time builder;
- testing/sharing → guided wizards.

## 25. Use progressive scaffolding for difficult inputs — IMPLEMENTED

The site now combines:
- examples;
- structured card/checkbox/select choices;
- sentence starters;
- question banks;
- "Need a starting point?" helpers;
- "I'm not sure yet" where uncertainty is meaningful;
- a built-in Task Breakdown Helper;
- editable open responses after scaffolds.

## 26. Add a Task Breakdown helper — IMPLEMENTED

The external AI Task Breakdown Guide was replaced with an in-site Task Breakdown Helper. It asks smaller questions about:
- what the learner can already do;
- which mapped step first changes;
- what smaller kind of thinking may be involved;
- what direct clue supports that best guess.

It produces a "Draft best guess to test" and can copy that draft into the Task Map for student/facilitator review. It never supplies evidence.

## 27. Do not require a separate AI window just to complete the website — IMPLEMENTED

Empathize and Define can now be completed entirely inside the League website. External AI remains optional for the short simulated interview practice. The Task Breakdown support that previously required an external AI window is now built into the site.

Later stages may still offer approved external AI as a deliberate project/build option, but external AI is not required merely to understand or complete the Empathize/Define forms.
