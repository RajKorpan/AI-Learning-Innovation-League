# Session timing and density revision

This revision responds to the visual review of the Facilitators landing page and Session 1 page.

## Session pages
- Removed the 45/90 interactive toggle from the hero, agenda, and sticky utility.
- Agenda now shows both schedules at once in dedicated **45 min** and **90 min (2 × 45)** columns.
- Printable session plans also show both timing plans simultaneously and no longer use a duration toggle.
- Reduced hero height and H1 size.
- Simplified the Key Question treatment to a quiet left-rule rather than a large box.
- Kept only **Open student stage** and **Print** as top actions.
- Sticky utility appears only after top actions scroll away and now contains only session identity, Student stage, and Print.
- Rebuilt Before the session as three open columns: Prepare, Watch for, and If students get stuck, try asking.
- Removed the Facilitate eyebrow so the agenda has one heading.
- Tightened activity rows and added explicit time-column headers.
- Simplified Quick Check to one heading and a smaller panel.

## Facilitators landing page
- Removed the duplicate session-shortcut navigation above the session entries.
- Compressed recurring preparation guidance into one block.
- Reworked the five session cards into a compact vertical session index with resource links aligned to each session.

## Navigation retained
- Top navigation keeps Facilitators as a single direct link.
- Facilitator session links remain in the footer and bottom-of-session navigation.
- Student stages remain in the footer and bottom-of-stage navigation.
