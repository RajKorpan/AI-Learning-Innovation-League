# Session Page Refinement Implementation

This revision follows the screenshot review and focuses on reducing duplication and making the pages faster to use during live facilitation.

## Session pages
- Removed the redundant facilitator-session eyebrow from the hero.
- Removed the three-column hero metadata strip.
- Consolidated 45/90 timing, student-stage access, and Print into one compact top utility row.
- The sticky utility is hidden in the opening viewport and appears only after the original controls scroll away.
- Reduced hero size and vertical padding.
- Kept the five-session journey but made it thinner and quieter.
- Simplified `Before the session` to one label plus `Prepare`; removed `Prepare for…` and the nested duplicate `Prepare` heading.
- Removed the repeated Preview Student Stage action from preparation.
- Lightened and tightened the Watch For / facilitator-prompt panel.
- Changed `Run the session` to `Agenda` and removed the third visible 45/90 selector.
- Tightened activity rows, narrowed the time column, shortened student activity links, and shortened `Students produce` to `Output`.
- Reworded 90-minute timing as M1/M2 meeting timing rather than nested Session 1/Session 2 wording.
- Reduced the size and visual weight of Quick Check and changed its heading to `Ready to move on?`.
- Added a compact all-session index at the bottom plus full previous/next labels.

## Navigation
- Removed the Facilitators dropdown from the global top navigation on every public HTML page.
- Facilitators now links directly to the Facilitators landing page.
- Facilitator session pages remain available in bottom/footer navigation.
- Footer Student navigation now includes Student home plus all six student stages.
- Each student stage now has a compact six-stage bottom index and full previous/next stage labels.
