Student Tool-Creation Process

From learning challenge to tested prototype.

Use this seven-step process to create an AI-supported learning aid that helps a learner think, practice, explain, reflect, or receive useful feedback.

  1. Define the learning goal.
    State what the learner should know or be able to do.
  2. Identify the specific challenge.
    Describe exactly where the learner gets stuck and what evidence supports that diagnosis.
  3. Analyze task components.
    Break the task into knowledge, concepts, procedures, decisions, reasoning, and checking.
  4. Select a learning strategy.
    Choose an evidence-based strategy that directly matches the challenge.
  5. Design the AI interaction.
    Define the AI role, sequence, feedback, hints, limits, and learner responsibilities.
  6. Include safety and privacy.
    Protect personal information, require accuracy checks, and preserve human oversight.
  7. Test and revise.
    Observe a user, collect evidence, improve the design, and record remaining limitations.
Final student package

What to submit

Design brief

Learning goal, challenge, task analysis, selected strategy, intended learner, and rationale.

Prototype

Working no-code tool, remixed example, structured prompt, storyboard, or clickable mockup.

Evidence

Safety review, user-test notes, revision log, reflection, and explanation of limitations.
