# Stage 3 implementation — Define + Ideate

Implemented from the agreed Stage 3 plan:

1. **Learning objective + success evidence** are now core project variables created in Define and carried forward.
2. **Learning Breakdown Mapper** now includes a true step-by-step Task Map with learner action, required knowledge/decision, status, and evidence at each step.
3. **Task Breakdown Guide** is an optional prompt for an advisor-approved AI tool. It explicitly produces a draft hypothesis, not a diagnosis, and feeds students back into their own Task Map.
4. **Strategy-category preparation** teaches a limited set of challenge types in plain language and includes three quick practice cases before students classify their own project.
5. **Strategy Explorer** recommendations now explain why they may help, what the learner should do, what the tool should do, how to know whether it worked, and possible product forms.
6. **Resource Inventor** now includes the learning objective, strategy, available materials, learner interests, grouping, time, practical constraints, accessibility needs, and a request for multiple alternatives.
7. **Resource Inventor reflection loop** asks what happened after an activity is tried and what should change next.
8. **Connected state** carries the focused problem, objective, evidence of success, strategy, and resources into Prototype and Test where feasible.
9. Advisor **Lesson 2 (Define)** and **Lesson 3 (Ideate)** were updated so facilitation guidance matches the revised student tools.

Outside research claims are not required in the core Define path; students rely primarily on direct interview, observation, and learner-work evidence.
