# Stage 1 Guided Experience Revision

This revision changes the five Advisor lesson pages and six Student stage pages from long scrolling documents into guided, one-screen-at-a-time experiences.

## Implemented

- One major task or decision is shown at a time.
- Back/Next controls and a progress meter guide users through each page.
- A compact "See all steps" control allows direct navigation without exposing all content at once.
- Each guided screen includes a visual illustration.
- Existing detailed instructions and interactive tools remain available within the relevant step rather than being removed.
- Advisor Lesson Plans reveal one activity at a time after the advisor selects the 45-minute or two-session format.
- Need More adaptations remain detailed but open one at a time.
- Student stage status language uses Start here / Up next / Coming later rather than Not started.
- Student-visible jargon was reduced or rephrased where possible; formal concepts remain when they are important to the League.
- "Small is good" reminders were added to Define, Ideate, and Prototype and their corresponding advisor lessons.
- Student and advisor guided interfaces include responsive layouts, larger touch targets, wrapped controls, and visual-first mobile presentation.

## Progressive enhancement

The detailed HTML remains in the page. JavaScript controls which step is visible. This preserves the substantive content and provides a readable fallback if JavaScript is unavailable.
