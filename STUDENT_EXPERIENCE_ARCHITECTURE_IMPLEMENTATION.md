# Student Experience Architecture Implementation

This revision rebuilds the Students landing page and all six student stages around the action-first architecture requested on 2026-08-27.

## Site-wide student system
- One primary task per guided screen.
- No “See all steps.”
- Quiet Step X of Y progress, Back, Continue.
- Examples are collapsed behind “See an example.”
- Persistent Need help? affordance on every stage.
- Stage-specific access questions integrated at the decision where access matters.
- Bottom six-stage journey with current stage emphasis and subtle completion checks.
- One conclusive completion screen per stage with artifact checklist, facilitator check, download, complete, and next action.
- Important project information is carried forward through browser storage rather than repeatedly requested.

## Students landing
Six major zones: hero, journey, team work pattern, project lens, support level, begin. Examples, related-page blocks, reset, and detailed stage descriptions were removed from the hero.

## Empathize
Five steps: assumption challenge; plan/conduct interview with embedded Question Detective and optional AI practice; visual Empathy Map; check together; finish.

## Define
Four steps: specific-problem challenge; visual Task → Steps → Change → Focus mapper; check together; finish. Learning goal and success sign are generated inside the mapper instead of becoming another stage step.

## Ideate
Six steps: learning moves; Strategy Explorer; five deliberately varied non-AI ideas; AI variety prompt; compare/shortlist; check + finish.

## Prototype
Seven steps: prototype contrast; select one of three paths; shared prompt foundation; pathway-specific build workspace; make the actual prototype; one-question-at-a-time design gate; check + finish.

## Test
Six steps: evidence challenge; Test 1 plan; observation/evidence workspace; revise and optional Test 2; visual iteration history; check + finish.

## Share
Six steps: evidence-sized claim; story focus; guided portable story; something useful to show; portable share-out; check + finish with a restrained celebration.
