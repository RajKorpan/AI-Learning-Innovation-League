Testing and Revision

Use evidence to improve the tool.

A strong prototype is tested with a real or representative user, observed carefully, and revised for learning value, usability, safety, and accuracy.

Tester instructions

  • Use the tool naturally.
  • Think aloud when possible.
  • Explain what seems clear or confusing.
  • Notice whether the tool makes you think.
  • Flag incorrect, unsafe, or unfair responses.

Designer observation

  • Where did the user get stuck?
  • Did the AI follow the intended strategy?
  • Did it give too much help?
  • Was feedback accurate and useful?
  • Did any privacy or safety issue appear?
Revision log

Record meaningful changes

  1. Describe the most important problem observed.
  2. Identify the evidence that showed the problem.
  3. Explain the change made.
  4. Predict how the change should improve learning or usability.
  5. Retest when possible.
  6. Document a limitation that still remains.
