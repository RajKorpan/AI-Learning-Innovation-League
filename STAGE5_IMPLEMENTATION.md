# Stage 5 implementation — Test + Iteration + Saving/Offline

Implemented from the agreed Stage 5 plan:

1. **Test begins with the learning objective and evidence of success** created in Define. Those values are carried forward automatically and can be reviewed before a test is planned.
2. **Testing separates learning from completion/usability.** Students record what the learner did, what the learner said/explained, where they still struggled, whether the interaction worked as expected, and whether any access/usability barrier appeared.
3. **League signature AI check:** every test asks whether the learner did the important thinking or whether AI/the tool did too much. Students justify that judgment with evidence from the interaction.
4. **Required evidence-linked revision:** every completed test finishes with “Because of testing, we changed…” and the revision appears in the version history.
5. **Visible prototype/version history** shows successive tests, evidence, and revisions so iteration is part of the student learning experience rather than a hidden overwrite.
6. **Printable/offline core activities** are available directly from Empathize interview work, Define Task Map, Ideate Strategy Explorer and Resource Inventor, Prototype Build Planner, and Test.
7. **Standard Save Your Work panels** now appear on every student stage. Each stage states what students should have before moving on and can download a single stage record from browser-local work.
8. **Cross-stage project continuity** is strengthened: the focused problem, learning objective, and success evidence from Define appear in Test; prior testing records feed the Share story; existing Strategy/Resource/Prototype state remains available from Stages 3–4.
9. **Advisor Lesson 5** now explicitly teaches the difference between completion and learning, the AI-doing-too-much check, evidence-linked revision, and visible iteration.

No login/account system was added. Work remains browser-local unless the student downloads it.
