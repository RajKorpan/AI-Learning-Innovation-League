Five-Lesson Curriculum

Lesson 4: Ideate and Prototype

This lesson develops the Ideate + Prototype mode and creates a project artifact for the shared team product.

Learning goals

  • Generate multiple learning-tool concepts.
  • Decide whether AI adds genuine value.
  • Select a product type based on the learner action and evidence.
  • Create a low-resolution prototype that answers one question.
  • Apply privacy, accessibility, agency, and fading checks.

Core activities

  • Compare paper, activity, prompt, Gem, and application concepts.
  • Use the prompt builder when conversational AI fits.
  • Create a storyboard, role-play, paper flow, sample set, or wireframe.
  • Write a prototype question and test plan.

Suggested lesson flow

  1. Launch with a concrete learner or teacher-client example.
  2. Introduce the core concept in student-friendly language.
  3. Model one process while making thinking visible.
  4. Students complete an active team task.
  5. Save the project artifact.
  6. Complete the responsible AI, accessibility, and reflection checkpoint.

Advisor questions

  • What evidence supports this decision?
  • What does the learner still have to think or do?
  • Whose experience or need is missing?
  • What assumption could testing prove wrong?
  • What is the simplest next prototype?
Student AI Learning Innovation League

A human-centered learning-design program in which students investigate authentic learning challenges, use learning science, create and test learning tools, and improve them through evidence and feedback.
