# Stage 4 — Facilitator-page implementation

This pass reworks the five facilitator guides around the stabilized student journey.

## 42. Do not duplicate the student page — IMPLEMENTED
The facilitator guides no longer reproduce student tools or student forms. They contain only preparation, facilitation prompts, watch-fors, stuck prompts, outputs, checks, and deep links to the actual student activities.

## 43. Consistent compact structure — IMPLEMENTED
Every guide uses Mission, Key question, Before the session, Activities, What students should produce, and Quick check. The existing Before the session / While you facilitate toggle remains.

## 44. Stage-specific purpose only — IMPLEMENTED
Generic repeated Why this matters sections were removed. Each guide has one stage-specific Mission and Key question.

## 45. Bullets rather than forced visuals — IMPLEMENTED
Facilitator guidance uses compact bullets/cards. Decorative guided-screen visuals were removed from the facilitator-body flow; visuals remain where they are useful in the student experience.

## 46. Keep print option — IMPLEMENTED
Each facilitator guide retains Print session plan. The five print pages were rebuilt to match the compact facilitator structure and selected 45- or 90-minute pathway.
