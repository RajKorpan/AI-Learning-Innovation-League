Student + advisor tool

Choose it, route it, and make it small Guided Build Planner

This one guided tool replaces three separate decisions. First it compares concrete product forms. Then you choose the form, confirm a technical pathway, and plan the smallest version worth testing.

Technical pathways are not ranks.

A printable activity, physical game, or practice routine can be a stronger project than an app. Use only the technology the learning interaction actually needs.

Decision 1

★
Example in action · Choose the form

Product choice

A physical/interactive activity scores higher than conversational AI because the learning target depends on seeing and measuring relationships.

★
Example in action · Build only what you need to test

Smallest useful version

Three lines, one ruler, and one prediction/measurement sequence are enough to test the central interaction.

Student tool · only when AI conversation fits

Teach the AI how to support learning Guided Prompt Builder

This is not a shortcut around prompt writing. You write a first attempt, then the builder asks you to make your learning-design decisions explicit. Afterward you compare, test, and revise.

What should your first prompt do?

Explain the AI’s job in plain language: what it should help the learner do, how it should interact, and what it should avoid doing. Do not try to make it perfect. The guided builder will help you notice what is missing.

Question 1

Test Draft 1 before you revise it

Try the prompt in an approved AI platform using a privacy-safe test case. Then record what actually happened.

★
Example in action · Use AI only when the interaction needs it

AI branch?

The team skips Prompt Builder. AI is not needed for the learner-facing activity; it might only help generate additional examples later.

Student + advisor

Required build checkpoint

Before polishing, confirm the learning action, build form, productive struggle, accessibility, platform requirements, privacy, and testing plan. If a paper role-play can answer the main question, test that before building more.

Accessibility check

Can the learner understand the instructions, control the pace, and access the important information? Does the design rely heavily on reading, sound, vision, precise motor input, one device, or reliable internet? Build an alternative where needed.
