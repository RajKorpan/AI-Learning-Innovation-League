Five-Lesson Curriculum

Build shared knowledge before students build tools.

The five lessons integrate learning science, AI literacy, task diagnosis, responsible design, and iterative testing.

Curriculum at a glance

Five lessons, one design journey

1

Humans Learn; AI Generates

Human learning, prior knowledge, practice, understanding, generative AI, pattern prediction, and cognitive offloading.

2

Diagnose the Learning Challenge

Metacognition, task analysis, peer interviews, evidence, and moving from broad difficulty to a precise need.

3

Match the Challenge to a Strategy

Retrieval practice, elaboration, worked examples, feedback, chunking, self-explanation, and strategy selection.

4

Design an AI-Supported Learning Aid

Role, audience, goal, sequence, feedback, limits, prompting, privacy, accuracy, and responsible use.

5

Test, Revise, and Share

User testing, observation, output evaluation, revision, reflection, limitations, and presentation.

Recommended structure

Each lesson should include

Learning goals

What students should know, explain, or be able to do by the end of the lesson.

Core concepts

Learning-science and AI-literacy ideas introduced in student-friendly language.

Interactive activity

A sort, model, interview, analysis, design task, or user test that requires active thinking.

Student artifact

A concept map, challenge statement, strategy rationale, prompt draft, prototype, or revision record.

Advisor guidance

Preparation, timing, likely misconceptions, discussion prompts, and adaptations.

Assessment check

A brief exit ticket, reflection, observation, or rubric checkpoint.

Suggested pacing

Flexible delivery options

Five sessions
Full lesson sequence
Teach one lesson per meeting, then continue into extended club project work.
Mini-lessons
Integrated project sessions
Use a short lesson at the start of each meeting, followed by student work time.
One-on-one
Tutoring adaptation
Use the same sequence with more guided questioning, self-reflection, and external peer feedback.
Boot camp
Intensive format
Combine selected lessons with build and feedback blocks across a full day or weekend.
Student outcome

What students should be ready to do

  • Define a clear learning goal
  • Identify a specific learning challenge
  • Analyze task components
  • Select an appropriate learning strategy
  • Design an AI interaction aligned with the strategy
  • Include safety, privacy, and accuracy safeguards
  • Test, revise, and explain the tool
Curriculum design

How the five lessons connect to the student project

LessonCore ideaProject contribution
1Human learning differs from AI output generation.Students define what responsible learning support should preserve.
2Broad difficulty must be translated into a precise challenge.Students create a specific challenge statement and task analysis.
3Different challenges require different learning strategies.Students select and justify a strategy.
4Prompts can encode learning goals, interaction rules, and safeguards.Students create a prototype or storyboard.
5Testing reveals whether the tool supports learning safely and effectively.Students collect evidence and revise.

Advisor preparation recommendations

  • Read the full lesson before facilitating it.
  • Choose age-appropriate examples from students' STEM subjects.
  • Prepare both technology-based and no-technology activity options.
  • Anticipate misconceptions about AI understanding, accuracy, privacy, and fairness.
  • Decide which student artifact will be saved after each lesson.
  • Plan brief formative assessment and reflection at the end of each session.
